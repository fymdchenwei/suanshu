# 算数小恐龙

小恐龙闯关岛是给小学一年级用的离线口算练习。一轮 30 道 100 以内的加减法，小恐龙踩着石头过关，每 10 题打开一次宝箱，收下奖励卡片。

## 网页版

地址：<https://fymdchenwei.github.io/suanshu/>

用手机 Safari 打开即可。第一次加载完成后可以离线玩，进度记在这台手机的本地存储里（奖励卡片、每轮成绩、各难度最佳星星、静音）。没有账号，也没有服务器。以前收集的贴纸会自动变成「以前的贴纸」回忆卡，不会丢掉。

画面按 iPhone 15 Pro 横屏来做。竖着拿会提示转成横屏。按钮比较大，避开刘海和底部横条。

### 添加到主屏幕

1. 用 **Safari** 打开上面的地址（不要用微信或其他内置浏览器）。
2. 点底部分享按钮。
3. 往下找到 **添加到主屏幕**，名称保持「算数小恐龙」。
4. 从主屏幕点图标打开。它会全屏显示，方向是横屏。

### 怎么更新

网页会在后台检查新版本。更新发布之后：

1. 完全关掉从主屏幕打开的算数小恐龙（从多任务界面划掉）。
2. 再从主屏幕打开一次。

如果还是旧的，用 Safari 打开同一地址，下拉刷新，然后重新「添加到主屏幕」（可以先删掉旧图标）。静音、卡片和成绩都在本机，刷新页面不会清掉。画面更新后服务工会换成新的缓存（`suanshu-v5`），按上面的步骤就能在手机上看到新画面。

### 怎么玩

首页是浮在云上的小岛，小恐龙会眨眼、摇尾巴。上面一排是累计一次答对的题数、奖励卡片和最高连对。下面四个难度，选好后按 **开始闯关**。不同难度的小岛颜色不一样，挑战难度是夜空。

| 难度 | 题目 |
| --- | --- |
| 轻松 | 20 以内，不进位、不退位 |
| 进位 | 20 以内，必须进位或退位，例如 8 + 7、13 − 5 |
| 进阶 | 20 到 99 的两位数加减一位数，不进位不退位，例如 40 + 7、56 − 6 |
| 挑战 | 100 以内，必须进位或退位。加法结果至少是 21，并且有一个两位数，例如 38 + 47、28 + 5。减法从 21 起步 |

一轮 30 题，分 3 关，每关 10 题。加减法交替，各 15 题。同一轮不重复（3 + 5 和 5 + 3 算两道）。得数在 0 到 100，没有负数。

答错没有惩罚：算式轻轻晃一下，出现「再试一次～」，还是这道题。星星只看 **第一次就答对** 的题数：27 题及以上 3 颗星，21 到 26 题 2 颗星，不到 21 题 1 颗星。做完一轮至少 1 颗星。只有 1 颗星时，结算画面是「再加油！」，并送一张安慰卡片，不会出现「闯关失败」。连对 5 题、连对 10 题会单独庆祝。每做完 10 题，宝箱打开，按成就收下奖励卡片（例如「本关答对 10/10 题」「连对 10 题」「全程零错误」）。

中途按「小岛」离开，这一轮的成绩不保存；这一轮已经拿到的卡片会留下。

声音是网页里合成的，没有音频文件。连对越多，答对的音会越高。右上角可以静音，这个选择会记住。第一次点屏幕之后才会出声（手机浏览器的限制）。

奖励卡片本里至少有 24 张卡，分普通、稀有、史诗、传说。还没拿到的是剪影，写着怎么解锁。点开一张可以跟着手指或手机倾斜闪一下。

### 本地开发

```bash
cd web
npm install
npm test
npm run dev
```

开发地址是 `http://127.0.0.1:5173/suanshu/`。打包：

```bash
npm run build
npm run preview
```

出题规则在 `web/src/engine/questionEngine.ts`，对应 iOS 工程里的 `QuestionEngine`。单元测试用 `npm test`。

### 发布到 GitHub Pages

工作流是 `.github/workflows/pages.yml`（Actions 里的 **Deploy web**）。推到 `main` 会构建 `web/` 并部署。也可以在 Actions 页手动 **Run workflow**；工作流文件在默认分支上之后，手动运行时可以选其他分支（例如还没合并的网页分支）。

仓库 Pages 的 Source 必须是 **GitHub Actions**。如果还没改过：打开 **Settings → Pages → Build and deployment → Source**，选 **GitHub Actions**。

部署完成后的地址是 <https://fymdchenwei.github.io/suanshu/>。Vite 的 `base` 是 `/suanshu/`，和这个地址对应。
